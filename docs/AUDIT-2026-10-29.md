# copyproof audit, 2026-10-29

Unattended overnight audit of `master` at `3d134f8`. Scope: the skill in `skill/copyproof/` (Node scripts, the zero-dependency review server, the review page) and the repo around it.

## What it is and how it runs

copyproof is a Claude Code skill. Claude extracts every user-facing string in a project into `<project>/.copyproof/copy.json` (`candidates.mjs` → extraction → `merge.mjs`), optionally screenshots each screen and records where each string sits (`locate.mjs` / `/api/locate` → `set-boxes.mjs`), then `serve.mjs` serves a local review page on `127.0.0.1:4477+`. The user rates, rewrites, tags and comments; the page writes `feedback.json`. `export.mjs` (or the page) turns the feedback into a revision prompt; **Apply this screen** queues a batch in `.copyproof/batches/` that `batches.mjs` hands to Claude. Node 18+, no runtime dependencies, no build step.

## Findings, ranked

### Bugs

1. **Removed strings vanish on the next rescan, leaving orphaned feedback** (medium, fixed). `mergeScan` keeps a deleted string as `status: "removed"` when it had feedback, so it shows under the **Removed** filter. On the next rescan that covers the same file, the removed item is neither an orphan (they're filtered out) nor in an uncovered file, so it's silently dropped from `copy.json` while its feedback stays in `feedback.json` with nothing pointing at it. Repro: scan `a.tsx` with two strings, rate one, rescan without it (removed, correct), rescan again (gone). `lib/merge.js:115`.
2. **`export.mjs --screen` only matches the exact screen name** (low, fixed). `--screen checkout` on a project whose screen is `Checkout` prints "Nothing flagged yet. Rate some strings 3 or lower…", which is wrong and misleading. Every other place (screenshots, locate, merge) matches screens by slug. `lib/core.js:150`.
3. **`--port 0` is ignored** (low, not fixed). `Number(args.port) || 4477` turns 0 into 4477, so you can't ask the OS for a free port. Harmless because serve walks up from 4477 anyway. `scripts/serve.mjs:270`.
4. **A malformed screenshot name returns a 500** (low, not fixed). `PUT /api/screenshot/%E0%A4%A` throws `URI malformed` from `decodeURIComponent`. Only the page calls this, with `encodeURIComponent`, so users won't hit it.
5. **"Saved" can show while a change is still pending** (low, not fixed). If you change something while a save is in flight, the first save's success sets "Saved" and clears the unsaved set; the second save follows 500 ms later. A reload in that window wouldn't carry the second change, but `pagehide` saves with `keepalive`, so in practice nothing is lost. `ui/app.js:1147`.
6. **A rescan can overwrite a rating made during the merge** (low, not fixed). `merge.mjs` reads `feedback.json`, then writes `copy.json` and `feedback.json`. A save from the page between the read and the write is lost (the 409 guard only covers saves after `copy.json` changes). The window is milliseconds.

### Security

The server is careful: it binds to `127.0.0.1`, refuses any `Host` other than `localhost`/`127.0.0.1` (which blocks DNS rebinding), refuses cross-origin writes, keeps screenshot reads and open-in-editor inside their folders, and spawns editors without a shell. The page escapes every string it renders. No secrets in the repo or its history (one author, no keys, tokens or private keys in any commit).

1. **Any website can read your unreleased copy while the review server runs** (medium, fixed). `GET /api/locate?screen=…` answers with `Access-Control-Allow-Origin: *`, and the snippet it returns embeds every string on that screen (text and ids). A page you visit in another tab can `fetch('http://localhost:4477/api/locate?screen=Unsorted')` (the default screen name) or guess common names like Home, Settings or Sign in, and read the copy. The fix allows only loopback origins (`localhost`, `127.0.0.1`, `[::1]`, `*.localhost`, any port), which covers a dev server on the same machine. An app served from anywhere else falls back to pasting the snippet from `locate.mjs`, which SKILL.md already describes for CSP-blocked pages. Loading the URL with a `<script>` tag doesn't get around this: the snippet is an unnamed arrow-function expression, so nothing on the page can reach it, and cross-origin script errors are blanked. `scripts/serve.mjs:115`.
2. **Writes without an `Origin` header are accepted** (info). Browsers always send `Origin` on cross-origin POST and PUT, so this only lets local tools (curl, scripts) through, which is fine for a local-only server.
3. **Open-in-editor follows symlinks inside the project** (info). `inside()` checks the path, not the real path. Only the project's own symlinks are affected, and it opens an editor rather than reading the file.

### Accessibility basics

1. **Small touch targets on phone** (medium). At 390 px wide, **Edit**, **Discard** and **View on screen** are about 19 px tall (WCAG 2.2 asks for at least 24×24). The source location links are 18 px tall on every width.
2. **The export and voice text boxes have no label** (low). `#export-text` and `#voice-text` sit under a dialog heading but aren't tied to it, so a screen reader announces "edit text". An `aria-labelledby` on each would fix it.
3. **Keyboard hints show on touch screens** (low). Cards on phone still show `Enter`, `C` and `G` keycaps, which squeezes "Come back later" onto three lines (see `audit-phone-1-start.png`).
4. Good: every button has a name, the screen list is a labelled `nav` with `aria-current`, filters use `aria-pressed`, the save state and toasts are live regions, dialogs are native `<dialog>`, and nothing scrolls sideways on a phone.

### Performance

Fine. With 2,160 strings on 40 screens, the first cards render in about 90 ms, ten ratings with moves take about 100 ms in total, a screen switch about 16 ms, search about 80 ms, and building an 85,000-character prompt about 80 ms. The page renders one screen at a time (about 1,500 DOM nodes) and uses about 10 MB of heap. The 5-second refresh check is a few `stat` calls.

### UX rough edges

1. **Opening the export dialog overwrites `.copyproof/prompt.md`** (low). The prompt is saved 300 ms after the dialog renders, even if you only looked. SKILL.md's apply step uses `prompt.md` when it's newer than `feedback.json`, so a peek can change what "apply" does. Saving on **Copy prompt** only would be safer. Question for Bazil, since it's a behaviour change.
2. **All-caps, letter-spaced labels** (product question). Kind chips (`TOAST`, `ERROR`), stamps (`WEAK`), `YOU ARE HERE`, `YOUR REWRITE`, `REVISED` and `CLAUDE'S TAKE` are uppercase with tracking. That's the wayfinding design in `DESIGN.md`, but it goes against the sentence-case rule Bazil uses elsewhere. Not changed.
3. **The export summary's separator** renders as "reviewed ·1 flagged" with no visible space after the dot at small sizes. The source has a normal space; it's the font's narrow space next to the middle dot.
4. **"Nothing flagged yet" from `export.mjs --screen <typo>`** doesn't say the screen doesn't exist. The slug fix above covers case and punctuation; a real typo still gets the generic message.

### Dependency health

No runtime or dev dependencies, so nothing is outdated or vulnerable. `npm audit` has nothing to check. The only third-party files are the Overpass fonts, shipped with their OFL licence. The code needs Node 18+ (`||=`, Unicode property escapes; the new tests use the global `fetch` and `cpSync`, also fine on 18), matching `engines`. Playwright for the new browser tests is optional and not added to `package.json`.
